# Creative application icon artwork

These transparent rendered PNGs are Neotrix's 3D interpretations of the actual
installed application icons. Blender's identity belongs to the Blender
Foundation, Adobe application identities to Adobe, and Fusion's identity to
Blackmagic Design. They are not vendor-provided 3D models.

The built-in image-generation tool produced one asset per application using its
real installed icon as the identity reference. SOURCE.json contains the complete
prompt set and provenance. Original generated alpha is preserved. The application
scales and caches the images at runtime; no image generation is needed to run it.
